# Swell Skills

Skills, agents, and tooling for [Swell Commerce](https://www.swell.is) development.

## Install

### Claude Code (full plugin install)

```
/plugin marketplace add swellstores/skills
/plugin install swell-app@swell
```

### Cross-agent (skill only — Cursor, Codex, Claude Desktop, etc.)

```
npx skills add swellstores/skills
```
